# Design Artifacts

This directory contains design references for the PySide6 desktop UI.

- `dingmail-ui-redesign-plan.md` is the durable redesign plan.
- `dingmail-workbench-demo.html` and `dingmail-workbench-no-sidebar-demo.html` are static visual prototypes.

These HTML files are not runtime code, not release inputs, and not test fixtures. Update them only when a new design exploration needs to be preserved.
